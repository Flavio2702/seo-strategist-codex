# Provenienza

Questa implementazione è stata scritta in una nuova directory, con una nuova
cronologia Git, a partire da una specifica funzionale e da fonti primarie pubbliche.
Codice Python, fixture sintetiche, test, testi operativi, esempi e presentazione
dei report sono nuovi contributi prodotti con assistenza OpenAI Codex.

Le fonti consultate e le decisioni sono nel [registro](SOURCES.md). Il testo di
LICENSE proviene dall'Apache Software Foundation e non è un testo originale del
progetto. Le librerie opzionali non sono incorporate nel repository. Le demo sono
output generati dal codice su un server sintetico locale; non derivano da siti
di clienti o da dati proprietari.

Attribuzione per famiglie di file:

| Percorsi | Origine |
|---|---|
| seo_strategist/*.py | Nuova implementazione assistita da AI |
| tests/*.py | Nuovi casi derivati da requisiti e contratti pubblici; sito sintetico |
| scripts/*.py | Nuovi strumenti di riproduzione e verifica |
| AGENTS.md, README.md, docs/*.md | Nuove istruzioni, documentazione e risultati delle verifiche |
| examples/* | Dati dimostrativi inventati, senza persone reali |
| demo/report.* | Generati da scripts/demo.py attraverso la nuova implementazione |
| .github/workflows/*, pyproject.toml, .gitignore, .gitattributes | Configurazione nuova con formati pubblici standard |
| LICENSE | Testo ufficiale Apache License 2.0 |
| NOTICE | Nuovo avviso di attribuzione e limiti |

L'assistenza AI non costituisce una prova di titolarità, una certificazione clean
room o una garanzia di assenza di diritti terzi. Apache 2.0 è applicata ai contributi
originali concedibili. Il progetto non importa materiale di provenienza incerta.
